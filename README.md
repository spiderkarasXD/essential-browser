# Essential

Браузер на Chromium (Electron 45) в духе Zen и Arc: вертикальные вкладки, пространства со своими темами, закреплённые сайты, всплывающая адресная строка, панель «Сайт» с расширениями, онбординг при первом запуске.

## Запуск из исходников

```bash
npm install
npm start
```

## Сборка .exe

```bash
npm run dist
```

В `dist/` появятся установщик `Essential Setup <версия>.exe` и `Essential-<версия>-portable.exe`.

## Android

Версия для телефонов — в папке `android/` (Kotlin + системный WebView на Chromium). Интерфейс написан на HTML (`android/app/src/main/assets/ui`), а новая вкладка, предупреждение о сертификате, темы, иконки сайтов и список субъектов берутся при сборке прямо из файлов ПК-версии.

Есть: вкладки и пространства с темами, всплывающая адресная строка, новая вкладка с часами, закреплённые сайты, приватные вкладки (в отдельном профиле WebView), загрузки с кружком прогресса, поиск на странице, предупреждения о сайтах без HTTPS, настройки, оповещения о беспилотной опасности, автообновление из GitHub Releases, «браузер по умолчанию». Нет: расширений Chrome (Android WebView их не поддерживает) и импорта из других браузеров (Android не даёт читать их данные).

```bash
cd android
gradlew assembleRelease
```

Нужны JDK 17+ и Android SDK (`local.properties`: `sdk.dir=...`). Релиз подписывается ключом из `android/keystore.properties` (файл не в репозитории). Без этого ключа обновить уже установленное приложение нельзя: Android не ставит APK с другой подписью поверх. Храните копию ключа отдельно.

Автообновление на телефоне ищет в GitHub Releases самый новый релиз с файлом `.apk` и сравнивает версию с `versionName`. Поэтому при выпуске поднимайте `versionCode` и `versionName` в `android/app/build.gradle.kts` и прикладывайте APK к релизу.

## Горячие клавиши

Все привычные сочетания Chrome (Ctrl+T, Ctrl+W, Ctrl+Shift+T, Ctrl+Tab, Ctrl+L, Ctrl+F, F3, Ctrl+P, Ctrl+U, Ctrl+Shift+N и т. д.) плюс свои:

| Клавиши | Действие |
| --- | --- |
| Ctrl+S / Ctrl+Alt+C | скрыть/показать сайдбар |
| Ctrl+Alt+1…9 | пространство по номеру |
| Ctrl+D | закрепить сайт |
| Ctrl+Shift+C | скопировать ссылку |
| Ctrl+, | настройки |

Полный список — в «Настройки → Горячие клавиши».

## Расширения

API расширений Chrome (`chrome.tabs`, `windows`, `action`, `contextMenus`, `cookies`, `notifications` и др.) даёт [electron-chrome-extensions](https://github.com/samuelmaddock/electron-browser-shell), установку из Chrome Web Store — [electron-chrome-web-store](https://www.npmjs.com/package/electron-chrome-web-store).

- Перенесённые из Arc, Chrome, Edge и других — `<профиль>/extensions/<id>` (кнопка «+» в панели «Сайт»).
- Установленные из Chrome Web Store — `<профиль>/WebStore`, обновляются сами.

## Настройки

Открываются кнопкой ⚙, по `Ctrl+,` или по адресу `essential://settings` (работают и `chrome://settings`, `arc://settings`). Раздел можно указать сразу: `essential://settings/privacy`, `essential://settings/devices` (микрофон и камера для сайтов).

## Оповещения о беспилотной опасности

При первом запуске Essential спрашивает, в России ли вы, и если да, то в какой вы области. Если в этой области объявлена беспилотная опасность, браузер показывает карточку со звуковым сигналом и советом отойти от окон. Страна и область хранятся только на компьютере: браузер раз в минуту скачивает общий список по всем областям и сам находит в нём вашу.

Это не официальная система оповещения. «Нет опасности» никогда не значит «безопасно»: если источник молчит, устарел или недоступен, браузер показывает это явно.

Источник данных не вшит: пока он не задан, оповещения выключены и скрыты. Адрес задаётся в `alerts.js` (`DEFAULT_SOURCE`) или в «Настройки → Тревога» (`essential://settings/alerts`). Нужен https-адрес, который отдаёт JSON:

```json
{
  "updated": 1761400000,
  "regions": [
    { "id": "region-1", "name": "Название области", "drone": true, "since": 1761399000 }
  ]
}
```

`updated` — когда источник последний раз обновлялся (секунды Unix, данные старше 10 минут считаются устаревшими), `drone: true` — в области сейчас опасность.

Список для выбора встроенный — `subjects-rf.json` (89 субъектов). Область из ответа источника находится по `id` или по названию. Лучше всего, если источник пишет названия так же, как в `subjects-rf.json`: «Республика Татарстан» и «Татарстан» совпадут, а «Чеченская Республика» и «Чечня» — нет. Если область не нашлась, браузер покажет ошибку, а не «спокойно».

## Файлы

- `main.js` — основной процесс: вкладки, пространства, сессия, настройки, импорт, хоткеи, «браузер по умолчанию»
- `importer.js` — перенос истории, закладок и запросов из Chrome, Edge, Яндекса, Opera/GX, Brave, Vivaldi, Arc, Zen, Firefox
- `extensions.js` — расширения Chrome: загрузка, перенос из других браузеров, иконки и названия
- `index.html`, `ui.js`, `style.css` — верхняя панель и сайдбар
- `spotlight.*` — всплывающая адресная строка с подсказками
- `siteinfo.*` — панель «Сайт» (расширения, PiP, разрешения сайта)
- `find.*` — поиск на странице (Ctrl+F)
- `downloads.*` — список загрузок (кружок прогресса на панели, Ctrl+J)
- `media-preload.js` — выбранные микрофон и камера для сайтов
- `chrome-preload.js` — `window.chrome` как в Chrome (без него Google не пускает в аккаунт)
- `autofill-preload.js` — автозаполнение форм (почта, имя, телефон, адрес; без паролей и карт)
- `favicon.js` — иконки сайтов: своя иконка сайта → /favicon.ico → сервис иконок Google
- `alerts.js`, `alert.*`, `regions.*` — оповещения о беспилотной опасности: мониторинг, карточка с сиреной, выбор области
- `updater.js` — автообновление из GitHub Releases
- `warning.html` — предупреждение перед сайтом без HTTPS или с неправильным сертификатом
- `panel.*` — настройки и редактор тем
- `onboarding.*` — первый запуск
- `newtab.html` — страница новой вкладки
- `theme.js` — расчёт градиента темы
- `build/icon.png`, `assets/` — иконки
